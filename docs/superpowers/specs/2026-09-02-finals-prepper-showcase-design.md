# exam-kit Showcase 打磨设计

**日期：** 2026-09-02
**范围：** 方案 B：精雕展示与差异化
**边界：** 不改变现有三个渲染器的视觉与交互逻辑；不公开真实课程材料；不发布到任何外部平台。

## 1. 目标与定位

`exam-kit` 定位为轻量的课程资料到离线复习工具生成器：把课程材料整理成可背的复习提纲、可刷的复习题和可探索的知识图谱。

本轮目标不是扩展 AI 能力，而是建立一条可信的公开证明链：真实课程材料只做本地回放；公开仓库使用重新措辞、独立构造的衍生 MySQL demo，复现 HTML 渲染链路和展示效果。

成功标准：陌生用户从 README 能在 10 秒内理解价值，在 1 分钟内安装依赖，在 3 分钟内用确定性 demo 生成三份可打开的 HTML。

## 2. 数据边界

### 本地真实回放

使用用户提供的真实课程目录进行一次性本地验收。回放可读取资料、生成临时中间文件和临时 HTML，但不复制到仓库、不上传、不提交。报告只记录不含内容的统计，例如章节数、扫描文件数、警告数和产物数量。不得保留课程名、教师名、文件名、题目、图片路径或原始 HTML。

### 公开衍生 demo

公开 fixture 不含真实课件、原图、连续原文、私人信息或可还原的本地绝对路径。内容采用独立措辞和简单结构，覆盖 MySQL 关系模型、SQL 查询、事务/索引等代表性知识点，并包含原题来源标签的公开示例。README 明确写为 derived demo，不宣称复现真实课程原文。

## 3. 公开 showcase 结构

新增以下公开资产：

```text
showcase/
├── fixture/
│   ├── course.json
│   └── README.md
├── build_showcase.py
├── expected/
│   └── verification.schema.json
├── output/                 # 生成目录，不提交生成 HTML
└── verification.json       # 运行后生成的机器可读摘要
```

`build_showcase.py` 是确定性入口：读取公开 fixture，写入临时 `.final_prep` 中间 JSON，调用现有三个 renderer，输出到 `showcase/output/`，然后检查三个 HTML 均存在、非空、包含 HTML 文档头、课程标题、章节、知识点、题目和图谱节点。脚本不联网、不调用模型、不读取用户真实目录、不覆盖 fixture 源文件。

公开构建命令：

```bash
python showcase/build_showcase.py
```

为避免把 AI 阶段伪装成可复现模型调用，demo 明确证明的是确定性渲染链路；真实用户的完整路径（资料扫描、提取、AI 生成 JSON、渲染）在 README 中单独说明。

## 4. README 与 showcase

新增 README 首屏包含：

1. 一句话价值钩子；
2. 三份产物的真实衍生 demo 截图或可打开链接；
3. 一行安装命令；
4. 安装后可直接复制的 prompt；
5. 真实回放与公开 fixture 的边界声明；
6. 安全边界和已知限制。

README 后续章节说明触发方式、真实用户流程、文件结构、验证命令、`.ppt` 等格式限制和离线行为。不使用“支持一切”“全自动”之类不可验证表述。

如生成截图，截图只来自公开 fixture 产物，文件名带 `derived-demo`。若当前环境没有可靠浏览器截图工具，不伪造截图；先提供可复现 HTML 链接和静态验证结果，并把浏览器验收标记为 unavailable。

## 5. 浏览器与静态验收

新增验收入口优先使用本机已有 Playwright/Chromium；不新增浏览器下载依赖。验收覆盖：

- 桌面视口：三份页面能加载，标题和首屏内容存在；提纲目录、自测块、复习题控件、知识图谱 SVG/节点/依赖线存在；
- 移动视口约 390×844：无横向溢出，提纲侧栏可用，复习题底部区域不遮挡主要内容，图谱仍有可交互区域；
- 打印档：题目、答案和解析存在，打印样式不隐藏关键内容；
- 离线约束：不依赖 CDN、fetch、外部脚本或网络服务。

浏览器驱动不可用时，脚本仍执行静态 HTML 检查并输出 `browser_check: unavailable`，不得把它标记为通过。

## 6. 错误处理与安全

构建器采用失败即停并给出下一步的策略：

- fixture 缺失：指出具体路径；
- 字段缺失或类型错误：指出文件和字段；
- renderer 失败：保留子进程输出，停止后续成功声明；
- 产物为空或缺失：验证失败；
- fixture 或产物命中个人信息模式：阻断公开构建并报告文件与行号；
- 任何真实目录参数都不接受为公开构建器输入。

脚本不删除文件、不覆写源文件、不调用外部 API、不提交 Git、不上传材料。临时目录在构建结束后清理；输出目录只写 showcase 自己的生成文件。

## 7. 测试与验证资产

新增测试覆盖：

1. 干净状态下生成三份 HTML 和验证摘要；
2. 标题、章节、知识点、题目、图谱节点和自测内容断言；
3. fixture 与产物的隐私/本地绝对路径扫描；
4. Python 编译、单文件 HTML、无外部网络依赖回归检查；
5. 缺 fixture、缺 JSON、空章节和非法字段时的非零退出与可读错误；
6. 可用时执行桌面、移动、打印浏览器验收，不可用时明确记录 unavailable。

所有生成 HTML 和验证报告放在临时目录或 `showcase/output/`，不把生成物散落到仓库根目录。一次性验收规则固化成测试脚本，供后续维护者重跑。

## 8. 本轮不做

- 不修改三个 renderer 的视觉、布局和交互；
- 不实现模型调用或新的学习功能；
- 不公开真实 MySQL 课件、原图、文件名、题目或原始 HTML；
- 不引入数据库、服务器、登录或外部 API；
- 不自动脱敏后发布真实材料；
- 不发布到 GitHub、ClawHub、skills.sh 或 Tessl。

## 9. 验证门

实现完成后必须满足：

- 从干净 checkout 执行公开构建成功；
- 三份 HTML 均生成并通过内容断言；
- README 首屏在 10 秒内说明价值和运行入口；
- 安装路径没有新增明显摩擦；
- 不含秘密、私人路径、原始课程内容或不可复现依赖；
- 浏览器验收结果如实标记通过或 unavailable；
- 既有 renderer 行为没有被改动；
- 至少两个典型使用 prompt 的操作路径比空 README 基线更可执行。

## 10. 后续演进

持续观察 Universal Exam Prep、StudyForge、Exam Study Guide & Predictor、Exam Prep Workflow 和 Education Agent Skills 的安装方式、README、评估资产和来源标注。每次版本更新记录“为什么改”，保留 demo 构建与验收命令。本轮不做的浏览器截图自动化、真实课程脱敏工具和多 Skill 套件化，作为后续独立议题，不混入本轮提交。
